# Basic Rules

## Documentation
- Add a concise JSDoc comment to every public function. One sentence is enough; skip obvious params.

## Communication
- Be concise. No filler words, no restating what was asked.

## Interaction Log
After every interaction, write a summary to `internal-monologue/`. File name format: `YYYY-MM-DD_short-description.md`. Include: what was asked, what was changed, and any non-obvious decisions made.
